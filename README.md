# Sharwin Vas — Cinematic Portfolio

A polished, responsive personal portfolio for Sharwin Vas built from the supplied resume. It uses a custom cinematic visual system with a high-contrast dark interface, animated project visuals, responsive layouts, mobile navigation, a hover-pausing skills marquee and project build-note modals.

This version is intentionally **zero-dependency at runtime/build time**. That means `npm run build` works without downloading packages. The local development server and production preview are implemented with Node's built-in modules.

## Requirements

- Node.js 18+ recommended
- VS Code
- A modern browser

## Open in VS Code

1. Extract/open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run:

```bash
npm run dev
```

4. Open the local URL shown in the terminal, normally `http://localhost:5173`.

## Production build

```bash
npm run build
```

This creates the `dist/` folder.

Preview the exact production folder with:

```bash
npm run preview
```

## Scripts

- `npm run dev` — serves the editable `public/` folder locally.
- `npm run build` — copies the production website into `dist/`.
- `npm run preview` — serves the built `dist/` folder locally.

## Structure

```text
sharwin-portfolio/
├─ public/
│  ├─ index.html       # page structure + content slots
│  ├─ main.js          # resume content, interactions, project modal, navigation
│  └─ styles.css       # complete visual system + responsive styles
├─ dist/               # generated by npm run build
├─ build.mjs           # zero-dependency production build script
├─ server.mjs          # zero-dependency local/preview server
├─ package.json
└─ README.md
```

## Content editing

Most content is centralized in `public/main.js`:

- `skills` — bento skill categories and tags.
- `projects` — project titles, descriptions, metrics, technology tags and build notes.
- `education` — education history.
- `certifications` — certification list.
- Contact details are written in `public/index.html` and should be changed there if your public contact URLs change.

## Design notes

- Fully responsive desktop/tablet/mobile layout.
- Skills marquee pauses on hover.
- About text uses normal word boundaries and disables mid-word wrapping.
- Reduced-motion support is included for accessibility.
- No phone number exists anywhere in the site source.
- External links are only used where the resume provides an actual destination.
